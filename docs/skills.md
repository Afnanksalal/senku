# Development skill routing

Read the appropriate skill entrypoint and only needed references for a task. Installing a skill makes instructions available; it does not install npm/Python libraries, scientific models, assets or infrastructure. User requirements override visual defaults.

Most skills live under ~/.codex/skills/<name>/SKILL.md. REA lives at ~/.agents/skills/reverse-engineer-anything/SKILL.md. Use the current session catalog when paths differ.

| Work | Skills |
|---|---|
| Product/UI design | ui-ux, frontend-design, ui-ux-pro-max |
| Mobile conventions | mobile-uiux-pro-max; use actual platform guidance |
| Playful copy/brand principles | duolingo-ux-reference |
| 3D foundation/assets | r3f-fundamentals, r3f-geometry, r3f-loaders, r3f-materials, r3f-lighting, r3f-textures |
| 3D motion/input | r3f-animation, r3f-interaction; r3f-physics only for simulation needs |
| Custom rendering | r3f-shaders, r3f-postprocessing; threejs-webgpu only with target compatibility |
| Choreography | gsap-core, gsap-timeline, gsap-react, gsap-scrolltrigger, gsap-plugins, gsap-utils, gsap-performance |
| Engineering review | r3f-best-practices, three-best-practices, threejs-performance, threejs-debugging |
| 3D delivery | threejs-web, threejs-assets, threejs-accessibility, threejs-testing, threejs-deployment |
| Browser/accessibility verification | playwright, playwright-interactive, a11y-audit |
| Shipped-artifact investigation | reverse-engineer-anything; prefer ordinary source tools for available source |

The product swarm's logical roles are not instructions to delegate development work. Use actual session authorization and relevant policies for external actions and tool execution.
