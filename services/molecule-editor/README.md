# Molecular drawing service

This service builds a real browser-based molecule drawing document, isolated from the main application's React version. The gateway serves it at `/editor/`; it has no public host port and does not receive science-worker credentials. All scripts, fonts, CSS and WebAssembly assets are served locally. No external drawing service or API key is used.

The document is trusted first-party code with a versioned bridge. Both sides require the exact window source, same origin, per-mount random session, request ID and bounded allowlisted message shape. It accepts SMILES or a MOL structure and exports the actual editor's SMILES plus MOL drawing. The parent explicitly chooses whether to use the result or download it. The drawing does not establish chemical safety, activity, drug efficacy or binding.

Bridge bounds are 256 SMILES characters and 100 KB of MOL text. The workspace and scientific backend apply the stricter docking limits, including 160-character SMILES and validated small-molecule chemistry. Importing an SDF loads its first structure; it does not silently create a multi-compound screen. Manual molecule input remains available if drawing tools cannot load.

Build with `docker compose build molecule-editor`, then start through the main Compose stack and gateway. Runtime is non-root with read-only files. `/health` reports ready only when the built document exists. The static server restricts methods and resolved paths, sets MIME types including WebAssembly, uses a same-origin CSP, and serves content-hashed application assets.

`node tests/protocol.cjs` runs message-boundary checks. Browser rendering/export checks are recorded separately when performed. Dependencies and their license notices remain in bundled code. The drawing packages are Apache-2.0; React is MIT, and other transitive dependencies retain their own licenses. The root MIT license covers Senku's wrapper, not third-party software.

The isolated document permits JavaScript dynamic evaluation because a bundled parser builds fixed keyword predicates at startup. This exception is confined to the editor document CSP; scripts, workers and network connections remain same-origin, and the bridge never accepts executable JavaScript. It is not applied to the main application.

Verified on 2026-10-25: 24 message-boundary assertions and 31 actual headless-browser checks passed. The browser loaded CCO through the real drawing engine, placed a benzene ring using the actual toolbar/canvas, exported its SMILES, downloaded a six-atom/six-bond MOL drawing and imported it again. Wrong-session requests and forged parent responses were rejected. Host and iframe documents had no horizontal overflow at 320/375/768/1440px with normal and 200% root text. Narrow scientific toolbars scroll internally so their controls remain reachable. No paid science/provider calls, external runtime requests or JavaScript exceptions occurred. Tests are `tests/protocol.cjs` and `tests/browser.cjs`; the latter uses the root Playwright dependency against a running `/molecules` page, Chromium by default or `PLAYWRIGHT_CHROMIUM_EXECUTABLE` for a local browser.

The build bundles the engine worker's transitive imports separately and uses content-hashed worker/application filenames. Bundled legal comments are retained. `/editor/licenses/index.json` identifies the actual package versions and licenses; packaged license files are copied under that directory. Some published drawing packages contain copyright headers and license metadata but no standalone license file; their source references remain in the index.

The pinned SDK's resize callback originally ran before asynchronous drawing initialization and kept its throttled listener alive without disposal. The build applies a version-guarded adapter to that function only: resize waits for the real editor, queued work is canceled when the document closes, and all listeners are removed. Document teardown unmounts its owned React root and explicitly destroys every owned drawing-engine worker. A restored back-forward-cache document opens a fresh engine. The modification is disclosed in `/editor/licenses/SENKU_EDITOR_CHANGES.txt`.

Run `node services/molecule-editor/tests/lifecycle.cjs` from the repository root for 10 lifecycle assertions. Run `node services/molecule-editor/tests/navigation.cjs` against the running stack for five rapid navigation cycles, including resize during initialization and completed molecule exports. All five cycles were verified with zero browser exceptions and exactly one drawing worker before leaving, zero afterward. No scientific requests were submitted. The navigation report is written to `artifacts/ci/editor/navigation.json`.
